# Исследование алгоритмов сортировки строк

## Описание проекта

Данный проект посвящен исследованию эффективности алгоритмов сортировки строк на языке C++. Основная цель работы — сравнение производительности стандартных и специализированных алгоритмов сортировки строк, а также анализ количества посимвольных сравнений, выполняемых в процессе сортировки.

В рамках исследования выполняется генерация массивов строк различных типов и размеров, после чего проводится измерение:

- времени выполнения алгоритмов;
- количества символьных сравнений;
- влияния структуры строковых данных на производительность сортировки.

Проект выполнен в учебных целях и может использоваться при изучении алгоритмов, структур данных и анализа производительности программ.

## Реализованные алгоритмы

### Стандартные алгоритмы

- QuickSort
- MergeSort

### Специализированные алгоритмы сортировки строк

- Ternary String QuickSort
- MSD Radix Sort
- MSD Radix Sort with Switch to Ternary QuickSort

## Генерация тестовых данных

Для подготовки тестовых наборов реализован класс `StringGenerator`.

При генерации используются:

- заглавные латинские буквы;
- строчные латинские буквы;
- цифры;
- специальные символы.

Длина строк:
- от 10 до 200 символов

Размер массивов:
- от 100 до 3000 строк

Шаг:
- 100

---

## Типы тестовых массивов

### Случайные массивы

Полностью случайные строки без предварительной сортировки.

### Обратно отсортированные массивы

Строки располагаются в обратном лексикографическом порядке.

### Почти отсортированные массивы

Создаются на основе отсортированного массива с небольшим количеством случайных перестановок.

## Подсчет сравнений

Для анализа производительности реализован собственный компаратор строк.

Во время работы алгоритмов фиксируется:

- количество посимвольных сравнений;
- среднее время выполнения.

Для уменьшения влияния случайных факторов каждый тест выполняется несколько раз с последующим усреднением результатов.

## Результаты исследования

В ходе экспериментов было установлено, что специализированные алгоритмы сортировки строк демонстрируют более высокую производительность по сравнению со стандартными алгоритмами.

Основные выводы:

- обычный QuickSort показывает нестабильное время работы;
- MergeSort работает стабильнее, но выполняет большое количество сравнений;
- String MergeSort с LCP уменьшает число повторных посимвольных сравнений;
- Ternary String QuickSort значительно эффективнее при сортировке строк;
- MSD Radix Sort показывает хорошую производительность на больших массивах;
- MSD Radix Sort with Switch оказался наиболее эффективным среди протестированных алгоритмов.

Полученные результаты соответствуют теоретическим оценкам сложности алгоритмов сортировки строк.
